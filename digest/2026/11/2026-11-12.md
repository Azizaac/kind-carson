## 💡 Today I Learned (TIL) & Pro Tip
### 📌 Docker Best Practices: Use Multi-Stage Builds to Minimize Image Attack Surface

Never ship compilers, build tools, or source code caches into production containers:
```dockerfile
# Stage 1: Build
FROM golang:1.22-alpine AS builder
WORKDIR /app
COPY . .
RUN go build -ldflags="-s -w" -o server .

# Stage 2: Minimal Runtime
FROM scratch
COPY --from=builder /app/server /server
ENTRYPOINT ["/server"]
```
Result: Image shrinks from 800MB+ to under 15MB with minimal CVE vulnerabilities.
